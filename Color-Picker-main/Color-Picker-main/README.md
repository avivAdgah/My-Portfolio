<h1 align="center">Color Picker</h1>

<p align="center">A modern, minimal color picker built with React and Vite.</p>

## Features

- Native color picker alongside a HEX / RGB / color-name text input
- Live validation with inline error messages for invalid input
- HEX and RGB readouts with one-click copy
- Preset color swatches
- Responsive layout with light/dark theme support

## Built With

- [React](https://react.dev/)
- [Vite](https://vitejs.dev/)

## Getting Started

```bash
npm install
npm run dev      # start the dev server
npm run build    # production build
npm run preview  # preview the production build locally
npm run lint      # lint the project
```
